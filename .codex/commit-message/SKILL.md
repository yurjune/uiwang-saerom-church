# Detailed Commit Message

When creating a git commit, write a useful multi-line commit message.

Use:

- A concise subject line that starts with a conventional type prefix such as `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`, or `style:`.
- A body unless the change is truly trivial.
- The body should explain what changed, why it changed, notable implementation details, and verification performed.
